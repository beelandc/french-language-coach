## Examples

### Input/Output Examples

1. **Known topic — exact match**
   - Input: `GET /grammar/recommendations/?focus_area=Past Tenses`
   - Expected Output: 200, `focus_area="Past Tenses"`, `matched_topics=["Past Tenses"]`,
     `lessons` = up to 3 LessonSummary from topic "Past Tenses"
     (passe-compose, imparfait, plus-que-parfait), sorted by id ascending.

2. **Partial/keyword match (English)**
   - Input: `?focus_area=pronouns`
   - Expected: `matched_topics` contains "Pronouns"; `lessons` are Pronouns lessons
     capped at 3 (sorted by id: direct-object-pronouns, indirect-object-pronouns,
     relative-pronouns — note subject-pronouns is excluded by the cap).

3. **French keyword match**
   - Input: `?focus_area=pronoms`
   - Expected: maps to "Pronouns" topic via French keyword.

4. **Unknown focus_area — fallback**
   - Input: `?focus_area=Pratiquer davantage`
   - Expected: 200, `matched_topics=[]`, `lessons` = fallback general beginner lessons
     (beginner-difficulty lessons sorted by id, capped at 3). NOT an error.

5. **Empty string — fallback**
   - Input: `?focus_area=`
   - Expected: 200, treated as unknown, fallback general beginner lessons.

6. **Multiple topics matched, capped at 3**
   - Input: `?focus_area=tenses`
   - Expected: matches Verb Tenses, Past Tenses, Future Tenses; collect all lessons,
     sort by id ascending, return first 3.

### Edge Cases
- Whitespace-only `focus_area="   "`: trim -> empty -> fallback.
- Topic with more than 3 lessons (Pronouns has 4): return exactly 3, deterministic order.
- Empty lesson catalog (defensive): return `lessons: []`, no 500.

## AI Response

Implementation completed per the prompt. Key decisions during implementation:

1. **Matching strategy refined**: Initially used naive substring containment, which
   caused a false positive ("nouns" matched inside "pronouns"). Switched to regex
   whole-word (`\b`) matching to prevent short-keyword substrings from matching inside
   longer words. Both singular and plural keyword forms are included in the dictionary.
2. **Bilingual keyword dictionary**: `FOCUS_AREA_TO_TOPIC` covers all 9 lesson topics
   with English + French keywords (e.g. "pronoms" -> Pronouns, "passé composé" -> Past Tenses).
3. **Deterministic ordering**: matched lessons sorted by `id` ascending, capped at
   `MAX_RECOMMENDATIONS = 3`.
4. **Fallback**: unknown/empty/whitespace focus_area -> beginner lessons (never errors).
5. **Response**: `RecommendationResponse` with `focus_area`, `matched_topics`, `lessons`
   (list of `LessonSummary`, which includes lesson IDs per AC2).
