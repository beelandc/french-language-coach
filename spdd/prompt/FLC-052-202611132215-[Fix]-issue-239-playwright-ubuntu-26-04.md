## Context

### Current Codebase State
- The Vitest workflow runs on `ubuntu-latest`, now Ubuntu 26.04, and installs browsers with `npx playwright install --with-deps`.
- `playwright` / `playwright-core` are locked at 1.60.0, which does not support Ubuntu 26.04, so both Vitest jobs fail before running tests.

### Relevant Files
| File | Purpose | Key Lines/Functions |
|------|---------|---------------------|
| `frontend/package.json` | Dev dependency range | L64 `"playwright": "^1.60.0"` |
| `frontend/package-lock.json` | Locked versions | `node_modules/playwright`, `node_modules/playwright-core` at 1.60.0 (L13327-13350) |
| `.github/workflows/vitest-tests.yml` | CI job (unchanged) | `runs-on: ubuntu-latest` L23; browser cache L45-52; install L59-62; `npm run test` L64-67 |
| `frontend/vite.config.ts` | Vitest Storybook project using the Playwright Chromium provider (unchanged) | `test.projects[0].browser` |

### Existing Patterns
- Frontend dependencies are managed with npm and a committed lockfile; CI uses `npm ci`.

---

## Goal

**Primary Objective**: Upgrade Playwright to 1.64.1 so the Vitest jobs can install Chromium on Ubuntu 26.04 runners and run the tests.

**Secondary Objectives**:
- Keep the lockfile change limited to `playwright` and `playwright-core`.
- Confirm `npm run test` still passes locally.

---

## Constraints

### Architecture Constraints
- No workflow changes; keep `ubuntu-latest`.
- No other dependency upgrades (Vitest, `@vitest/browser-playwright`, Storybook stay as they are).

### Code Quality Constraints
- Lockfile generated by npm, not hand-edited.

### Testing Constraints
- Run `npm run test` (Vitest Storybook project, headless Chromium) locally with the upgraded version.
- Final proof is the PR's Vitest jobs on Node 20 and 22.

### Acceptance Criteria
1. `playwright` in `frontend/package.json` / `package-lock.json` is upgraded to a version that supports Ubuntu 26.04
2. Both Vitest Unit Tests jobs (Node 20 and 22) pass the "Install Playwright Browsers" step and run the tests on a PR
3. `npm run test` passes locally with the upgraded version
4. No other dependency changes beyond what the upgrade requires

## Examples

### Input/Output Examples
1. **CI install**
   - Input: `npx playwright install --with-deps` on ubuntu26.04-x64
   - Before: `ERROR: Playwright does not support chromium on ubuntu26.04-x64`, exit 1
   - After: Chromium and system dependencies installed, exit 0
2. **Version check**
   - Input: `npx playwright --version` in `frontend/`
   - Expected Output: `Version 1.64.1`

### Edge Cases
- An older browser restored from the Actions cache through `restore-keys`: `playwright install` downloads the revision 1.64.1 needs; the exact cache key changes because the lockfile hash changes.
- A newer Chromium affecting story tests: caught by the local `npm run test` run.

### Test Cases


## AI Response

Implemented by Claude Code (Claude Opus 5.5) from the Actual Prompt above.

- `cd frontend && npm install -D playwright@1.64.1`
- `frontend/package.json`: `"playwright": "^1.60.0"` → `"^1.64.1"`
- `frontend/package-lock.json`: `playwright` and `playwright-core` 1.60.0 → 1.64.1. Two side effects of the new package metadata, with no other packages changed: the `engines.node` field went from `>=18` to `>=20` (CI uses Node 20 and 22), and Playwright's nested optional `fsevents@2.3.2` entry was removed (1.64.1 no longer declares it).
- No workflow changes.
